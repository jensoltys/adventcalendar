# Contributing to Advent Calendar

Thanks for wanting to help.

## Report a bug or ask for a feature

Open an [issue](../../issues/new/choose) and pick the bug or feature form. Say what you expected, what happened, and the steps to get there. Mention whether it's on advent.jenbuiltit.com or your own copy.

Found a security problem? Don't open an issue. Follow [SECURITY.md](SECURITY.md) so it can be fixed before anyone else sees it.

## Pull requests

I'm not taking pull requests right now. That keeps the commercial license option possible, because I need to own all of the code to offer it. You're welcome to fork Advent Calendar and change it however you like under the [license](LICENSE).

## Run it and test it locally

You need Node.js 22 or newer. The README's "Run your own copy" section has the setup steps. `npm install` adds the pinned `wrangler` tool that runs the calendar on your computer. To run the tests:

```bash
npm install
npm test
```
