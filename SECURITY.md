# Security

Found a security problem in this advent calendar? Please don't open a public issue. Report it privately, so it can be fixed before anyone else sees it:

- On GitHub, open this repo's **Security** tab and click **Report a vulnerability**. Only the maintainer sees it.
- Or email **hello@jenbuiltit.com**.

Include what you found, the steps to reproduce it, and whether it affects advent.jenbuiltit.com or only self-hosted copies.
